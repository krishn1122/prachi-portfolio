# Prachi Goyal Portfolio

A modern personal portfolio website built with React, Vite, and TypeScript.

## Overview

This project presents the professional profile of Prachi Goyal as a Business Analyst and Project Coordinator, including background, experience, skills, certificates, and contact information.

## Tech Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS
- Lucide React

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
